# 标题整理：批量修复标题

免费思源插件，作用于当前打开的文档。OCR 扫描书籍或 PDF 导入后，很多整段文字会被识别成标题，本插件可一键把它们转回正文段落。

## 功能
- 标出看起来像句子的标题：以标点结尾，或长度超过设定值（默认 40 个字符）。
- 保留章节标题。你列出的词（默认：`章, 节, 题, Chapter, Section, Part`）出现在标题开头附近时，该标题会被保护；也支持 `/正则/`。
- 确认勾选后点击「将勾选项转为段落」。文字、行内格式和块 ID 保持不变。
- 「同时补齐层级断档」：转换后修复 h1 直接接 h4 之类的跳级。
- 「全部升一级 / 降一级」：整体调整标题级别（若会超出 h1 或 h6 则拒绝执行）。

## 使用方法
打开文档，点击顶栏的标题整理图标（或运行命令「打开标题整理」），检查建议项，点击按钮并确认。

思源的文档历史（右键文档，历史）会保留笔记的早期版本；大规模修改前请先检查。
